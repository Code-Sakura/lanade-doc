# requirement

経済シミュレーション * NFT * サンドボックス

## world

* 3d
* 一定の広さのスペースを区域とする
* 区域にはofficialと購入可能と未開拓な区域がある
    * officialはゲームとして必要な機能を提供する区域
    * 購入可能区域は購入者によって好きに用途を決めることができ、デザインすることができる
    * 未開拓区域は街の周りに存在する
* 中央にoffcialの区域がある区域群を街とする
* 街の中央のoffcial区域を駅とする
* 駅と駅同士でファストトラベルを可能にする
* 街を組み合わせて世界を作っていく
* 街が大きくなったとき、未開拓区域の一部が駅となり新たな街となる
    * その際に購入可能区域の属する街が再編される

## 経済

* 生産、加工、販売、戦闘を行うことで経済を形成する。
* 物品の売り買いは駅にある施設または個人間で行える
    * 駅ではその駅での販売と購入の量に応じて値段が設定される
    * 個人間では任意に設定できる

### 生産

* 資源のある区域で採掘、農耕などをすることでアイテムを生産できる

### 加工

* アイテムを利用して他のアイテムを生産する

### 販売

* アイテムをプレイヤーやNPCに向けて販売する

### 戦闘

* 未開拓の区域の敵を倒すことで区域を手に入れることができる

## NFT

土地とゲーム上に一つしかないユニークなアイテムはNFTで管理される
